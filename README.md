# AFHE-Web-App
Application Web pour l'Association des Femmes Handicapées pour l'Entrepreneuriat (AFHE).

# Fonctionnalités Globales de l'Application Web
Elle possède une fonctionnalité vitrine (site web vitrine) côté client qui permet aux internautes de visiter la plateforme en ligne permettant ainsi d'accroître la présence en ligne et la visibilité de l'AFHE.  <br>
Elle possède aussi une interface d'administration (back office) qui permettra à l'AFHE de gérer leur site web, et accessoirement l'association en interne
